# Allowlist for tools/pre_commit/check_test_tethering.py
#
# Every path below is a test file that is collected by NO Buildkite job - not in
# .buildkite/test_areas/ and not in .buildkite/test-amd.yaml. These are
# pre-existing gaps, captured when the check was first added so that the gate
# could start green. The list is meant to only ever shrink.
#
# Rules:
#   * Every entry needs a trailing `# <reason>` on its own line saying why the
#     test isn't wired into a job. A bare path is rejected by the check.
#   * Do not add a new entry to unblock a PR without a real justification.
#   * To remove an entry: add the test to a job's `commands` (and matching
#     `source_file_dependencies`) in .buildkite/test_areas/, then delete the line.
#   * `check_test_tethering.py --all` reports entries here that have since
#     become tethered, and entries whose file no longer exists.
#
# Tracking: https://github.com/vllm-project/vllm/issues/53944
