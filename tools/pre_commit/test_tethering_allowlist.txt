# Allowlist for tools/pre_commit/check_test_tethering.py

# Every path below is a test file that is currently collected by NO job in
# .buildkite/test_areas/. These are pre-existing gaps, captured when the check
# was first added so that the gate could start green. The list is meant to only
# ever shrink.
#
# "Untethered" here is scoped to .buildkite/test_areas/, which is all the check
# parses. A few entries below are still run by the legacy hand-maintained
# .buildkite/test-amd.yaml pipeline and are marked as such; they are listed
# because they have no coverage in the native pipeline that test_areas defines.
#
# Rules:
#   * Do not add a new entry to unblock a PR without a real justification and a
#     comment saying why the test cannot be wired into a job.
#   * To remove an entry: add the test to a job's `commands` (and matching
#     `source_file_dependencies`) in .buildkite/test_areas/, then delete the line.
#   * The nightly `check_test_tethering.py --all` run reports entries here that
#     have since become tethered, and entries whose file no longer exists.
#
# Tracking: https://github.com/vllm-project/vllm/issues/53944
